## 1. 한 줄 요약

엘리베이터가 존재하지 않는 층 **B58**에 멈춘다. 소녀는 부엌에서 눈을 뜨고, 젖은 나무 복도를 지나 인형의 방에 도착한다. 복도에는 **시선이 닿지 않을 때만 움직이는 무언가**가 있다.

- 장르: 고정 카메라 3인칭 서바이벌 호러 (탐색 + 회피, 전투 없음)
- 룩: 1999년 PS1/PS2 초기 감성. 저해상도, 정점 흔들림, 안개, 컷 전환
- 목표 분량: 이 문서의 범위 = 방 3개, 5~8분 플레이의 버티컬 슬라이스

## 3. 플레이어 캐릭터

- **소녀** (이름 미정 — 서사팀 결정 대기)
- 외형: 어깨 길이 흑발, 앞머리, 회색 긴소매 상의, 짙은 남색 치마, 흰 양말, 검은 단화
- 목업은 박스/구 조합의 로우폴리. 실제 제작 시에도 **800~1500 tris, 텍스처 128~256px** 수준 유지 권장 (룩 통일)

## 4. 조작 (탱크 컨트롤)

| 입력 | 동작 | 목업 수치 |
|---|---|---|
| ↑ / W | 전진 | 1.7 m/s |
| Shift + 전진 | 달리기 | 3.0 m/s |
| ↓ / S | 후진 | 0.9 m/s |
| ← → / A D | 제자리 회전 | 2.5 rad/s (≈143°/s) |
| Q | 180° 퀵턴 | 10 rad/s로 π만큼 회전 |
| E / Space / Enter | 조사, 대사 넘기기 | 대사 타이핑 38자/초, 누르면 즉시 완성 |

- 대사창이 떠 있는 동안 이동 불가
- 모바일: 화면 하단 가상 패드 (방향 4 + 조사 + 180° + 달리기)

## 5. 카메라

방마다 **고정 카메라 1대**, 방에 들어서는 순간 하드 컷(0.12초 노이즈 화면).

| 방 | 위치 | 시선 | FOV | 비고 |
|---|---|---|---|---|
| 부엌 | 방 구석 천장 근처 (3.5, 2.5, 0.5) | 방 중앙 ↔ 플레이어 35% 보간 | 78 | 레퍼런스 3의 하이앵글 광각 재현 |
| 서쪽 통로 | 플레이어 뒤 2.5m, 높이 1.72 | 플레이어 앞 3m | 64 | 레일 카메라(플레이어 z를 따라감). 1점 투시로 복도 끝이 보이게 |
| 인형의 방 | 입구 쪽 모서리 높이 3.15 | 방 중앙 ↔ 플레이어 30% 보간 | 72 | 레퍼런스 2의 탑다운 사선 구도 |

## 6. 위협: "그것" (복도의 존재)

레퍼런스 1의 웅크린 창백한 형체. 긴 팔, 앞으로 꺾인 상체, 고개가 불규칙하게 경련.

**규칙 — 시선이 닿지 않을 때만 움직인다**

1. 대기 위치: 복도 안쪽 (x −0.4, z 21.6)
2. 플레이어가 **8m 이내**에 들어오면 깨어남
3. 매 프레임 플레이어 정면 벡터와 "플레이어→그것" 벡터의 내적을 계산
   - 내적 **≥ 0.55** (대략 ±57° 안에서 바라보는 중) → **정지**
   - 그 외 → 플레이어 쪽으로 **1.45 m/s** 이동 (달리기보다 느리고 걷기보다 약간 느림)
   - 대사창이 열려 있는 동안에도 정지
4. **0.55m 이내** 접근 시 잡힘 → 붉은 화면 "들켰다" 1.8초 → 복도 입구에서 재시작, 그것은 원위치
5. 복도를 벗어나면(다른 방 진입) 원위치로 리셋

**설계 의도**: 복도 끝까지 가려면 그것을 지나쳐야 함 → 등을 보이는 순간이 반드시 생김. 퀵턴(Q)으로 뒤돌아 멈춰 세우고, 다시 돌아 달리는 리듬이 핵심 긴장.

## 7. HUD

최소한으로. 체력 바 없음.

- **좌상단**: `B58 · UNDERLEVEL` + 현재 방 이름 (부엌 / 서쪽 통로 / 인형의 방)
- **우상단**: 심전도(ECG) 미니 그래프 + 상태 텍스트
  - 위험도 = clamp((6 − 거리) / 4.5, 0, 1), 복도에서 그것이 깨어 있을 때만
  - < 0.2 `FINE` (녹색) / 0.2~0.6 `CAUTION` (주황) / > 0.6 `DANGER` (빨강)
  - 심박수 60 + 위험도×90 BPM, 위험도 0.15 이상이면 박동마다 저음 '쿵' 사운드
- **하단 중앙**: 조사 가능 지점 근처에서 `[E] 조사`
- **하단**: 대사창 (반투명 검정, 2px 테두리, 타이핑 효과, 완료 시 ▼)
- 복도에서만 좌하단 힌트: "그것은 시선이 닿지 않을 때만 움직인다."

## 10. 비주얼·사운드 규칙

**렌더**
- 내부 해상도 **320×240**으로 렌더 → 포인트 필터로 화면 확대 (픽셀 그대로)
- **정점 스냅**: 클립 공간 좌표를 160×120 격자에 반올림 (PS1 흔들림)
- 텍스처: 32~64px, Point 필터, 밉맵 끔
- 라이팅: 방마다 포인트 라이트 2~3개, 낮은 앰비언트. 정점 라이팅(Lambert) 느낌
- 안개: 검정에 가까운 녹색(#020302), 시작 2.6m / 끝 15m
- 화면 효과: 스캔라인, 비네트, 6초 주기 미세 플리커
- 통로 주황 조명은 4% 확률로 프레임 단위 깜빡임
- 인형의 방: 눈알 홍채가 항상 소녀를 추적, 매달린 인형이 미세하게 흔들림

**사운드** (목업은 WebAudio 합성, 실제는 에셋 교체)
- 앰비언트: 55Hz/58.3Hz 디튠 저음 드론 + 갈색 노이즈 웅웅거림
- 발소리: 걷기 0.45초 / 달리기 0.30초 간격, 복도는 더 둔탁하게
- 심장 박동: ECG와 동기
- 잡힘: 큰 '쿵'

**UI 폰트 (목업)**: 제목 Gowun Batang, 본문 Nanum Gothic Coding, HUD VT323
