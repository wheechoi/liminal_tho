# 시스템 — 조사 · 대사창 · 문

> 상태: **진행 중** · 작성: 기획 · 최종 수정: 2026-11-15 03:00

- **시스템**: 조사 지점, 대사창, 문 열기
- **상태**: `진행 중`
- **우선순위**: `높음`
- **관련 씬**: [씬 1-1](<씬 1-1 — 소희 기상.md>)
- **최종 수정**: 2026-11-15

> [!NOTE]
> 조사 지점 근처에서 E를 누르면 대사창. 문도 같은 키로 연다.

## 왜 필요한가

탐색형 공포 게임의 기본 상호작용. 조사 순서가 숨은 대사(6:56)의 조건이 된다.

## 규칙

1. 조사 지점 = 위치 + 반지름(범위 원). 가구에 붙은 지점은 가구를 옮기면 같이 따라감
2. 범위 안에 들어오면 하단에 “[E] 조사” / “[E] 문 열기” 안내
3. 대사는 여러 장: 빈 줄 = 다음 대사창. “이름: 대사”면 말하는 사람 표시. 대사창 높이를 넘으면 자동으로 다음 장
4. 대사 중에는 이동 불가. E/Space/Enter로 넘김
5. 처음 대사(lines) / 다시 조사(repeatLines) / 숨은 대사(secret) 구분. 숨은 대사는 조건(침실 4곳)을 채우면
6. 문: E로 열림, 문턱 있음. 잠긴 문은 대사만
7. NPC에게 말 걸기(`[E] 말 걸기`, 2026-11-15): 말하는 동안 NPC가 소희 쪽으로 몸을 돌리고 끝나면 제자리로, 소희도 상대를 봄. 엄마는 아일랜드 건너편에서도 (범위 2.4m)

## 조작

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| E / Space / Enter | 조사, 대사 넘기기, 문 열기 | 범위 안 |
| 마우스/터치 패드 | 모바일용 가상 패드(방향 4 + 조사 + 달리기 + 건너뛰기) |  |

## 화면 · UI

- 대사창: 어두운 판 + 가는 크림색 테두리 두 줄, Gowun Batang, 말하는 사람 이름(장밋빛), ▼ 넘김 표시
- 안내 문구: 화면 하단 가운데

## 예외 상황

| 상황 | 처리 |
| --- | --- |
| 대사 중 또 E | 타이핑 중이면 즉시 완성, 끝났으면 다음 장/닫기 |
| 문 범위와 조사 범위가 겹침 | 가까운 쪽 하나만 |
