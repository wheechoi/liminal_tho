# 시스템 — 목업 편집 모드

- **시스템**: HTML 목업 편집 모드
- **상태**: `확정`
- **우선순위**: `낮음`
- **관련 씬**: —
- **최종 수정**: 2026-11-15

> [!NOTE]
> 목업 안에서 카메라·가구·톤·조사 범위·구역·대사를 직접 고치고 “값 내보내기”로 유니티에 옮길 값을 뽑는 도구.

## 왜 필요한가

기획자가 코드 없이 배치·연출을 바꿔 보고, 확정값을 유니티로 넘기기 위해.

## 규칙

1. Tab으로 플레이 ↔ 편집. 편집 중 소희는 멈춤
2. 도구마다 되돌리기(Ctrl+Z/Y) · 저장(브라우저) · 값 내보내기
3. 직접 조정한 카메라·가구·톤·범위를 기본값으로 확정할 수 있음
4. 가족 NPC도 물건(`OBJS`)이라 물건 도구로 옮기기·돌리기, 텍스트 도구(N)로 대사 수정. 값 내보내기에 `[NPC]` 항목(유니티 모델 파일 이름 포함). 미희·엄마는 식당 모듈과 함께 이동

## 조작

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| Tab | 플레이 ↔ 편집 |  |
| C | 카메라 도구 — 구역 카메라 위치·방향, W/A/S/D/Q/E로 이동 |  |
| O | 물건 도구 — 클릭(떼는 순간)으로 선택, 끌어서 이동, R/F/Z/X로 회전·크기, 색 바꾸기, 액자 이미지 |  |
| T | 톤 도구 — 기본/구역별 톤 |  |
| I | 조사 범위 도구 — 범위 원 표시, 휠/슬라이더로 반지름 |  |
| V | 구역 도구 — 추가·이동·네 변 조절·크기 손잡이(흰 동그라미, 0.05m)·층·카메라 지정 |  |
| N | 텍스트 도구 — 가구·조사 지점 대사 편집, 글자 크기 |  |
| B | 에셋 보관함 |  |
| 숫자키 1~8 | 그 구역 카메라 고르기 / 그 구역으로 | 도구에 따라 |
| Delete | 보관함 물건 빼기 | 물건 도구 |
| L | 가족 NPC 기본↔가난 차림 미리보기 |  |

## 화면 · UI

- 오른쪽에 도구 패널(슬라이더·입력칸). 게임 화면을 클릭하면 입력칸 포커스가 풀려 키가 화면으로 감

## 예외 상황

| 상황 | 처리 |
| --- | --- |
| 한글 입력 상태에서 키(ㅈ→W 등) | 키 코드로 인식. keyup이 안 오면 눌림 신호가 끊긴 뒤 자동 정지 |
| 창 전환·오른쪽 클릭 메뉴 | 키 전부 놓기 |
