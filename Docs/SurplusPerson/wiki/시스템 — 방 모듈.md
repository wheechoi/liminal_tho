# 시스템 — 방 모듈

> 상태: **진행 중** · 작성: 기획 · 최종 수정: 2026-11-15 03:00

- **시스템**: 방 모듈 (1층 방 옮기기)
- **상태**: `확정`
- **우선순위**: `보통`
- **관련 씬**: —
- **최종 수정**: 2026-11-15

> [!NOTE]
> 1층 서재 · 식당(+부엌) · 손님방은 통째로 옮길 수 있는 모듈. 집 구조를 아직 정하지 못한 동안 배치를 쉽게 바꾸려고.

## 왜 필요한가

1층 방 3개의 정체가 미정이라 위치·크기를 여러 번 바꿔 볼 필요가 있음.

## 규칙

1. 편집 모드 물건 도구(O)에서 방 문을 끌면 방 전체가 거실 벽을 따라 이동
2. 같이 움직이는 것: 벽 구멍, 바닥, 가구, 조명, 카메라 구역, 조사 지점, 숫자키 이동 위치
3. 다른 방과 겹치거나 벽 밖으로 나가면 막힘
4. 부엌은 식당 모듈에 포함(식당 남쪽 아치)
5. 되돌리기(Ctrl+Z) · 저장 · 값 내보내기에 포함

## 조작

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| 편집 모드 O → 문 끌기 | 방 이동 | 거실 벽 범위 안 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 실행 |  |

## 화면 · UI

- 물건 도구에서 문을 고르면 방 전체가 선택 표시

## 예외 상황

| 상황 | 처리 |
| --- | --- |
| 방을 옮긴 뒤 숫자키 | 옮긴 방 위치로 이동 |
| 모듈이 겹침 | 겹치기 직전에서 멈춤 |

## 수치 · 데이터

| 항목 | 값 | 메모 |
| --- | --- | --- |
| 모듈 | 서재(x축), 식당+부엌, 손님방 | `MODS` axis/off |

## 구현 메모

> [!IMPORTANT]
> 유니티에서는 모듈 기능 없이 확정 위치로 배치하면 됨. 확정 뒤 “값 내보내기”로 좌표를 뽑는다.
