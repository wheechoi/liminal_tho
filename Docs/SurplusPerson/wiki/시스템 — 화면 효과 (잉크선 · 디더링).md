# 시스템 — 화면 효과 (잉크선 · 디더링)

> 상태: **진행 중** · 작성: 기획 · 최종 수정: 2026-11-15 03:00

- **시스템**: 화면 효과
- **상태**: `진행 중`
- **우선순위**: `보통`
- **관련 씬**: 전부
- **최종 수정**: 2026-11-15

> [!NOTE]
> 게임 화면을 480×360으로 그린 뒤 잉크 외곽선 · 디더링 · 색 제한 · 종이 질감을 입힌다. 4:3.

## 왜 필요한가

레퍼런스(단면 저택 일러스트, 1비트 만화, 픽셀 아트)의 공통점을 한 번에 내는 가장 싼 방법.

## 규칙

1. 내부 해상도 480×360, 포인트 필터로 확대
2. 화면 셰이더: 잉크선 + 디더링 + 색 수 제한 + 종이 질감
3. Gradient Map Amount를 올리면 화면 전체가 한 가지 색조(갈색~붉은색~크림)로 물듦. 1-1은 0. **공포가 짙어질수록 올리는 연출 손잡이**
4. 구역별 톤: 구역마다 바꾼 값만 따로 저장

## 조작

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| G | (목업) 그라디언트 맵 단계 바꾸기 | 개발용 |
| T | (목업) 톤 도구 — 기본/구역별 톤 편집 | 편집 모드 |

## 화면 · UI

- HUD: 왼쪽 위 장소, 오른쪽 위 개발용 줄, 아래 안내·대사창. 폰트 Gowun Batang / Nanum Gothic Coding
