## 위협 — “그것”

1. 복도 안쪽에서 대기. 플레이어가 8m 안에 들어오면 깨어남
2. 플레이어가 바라보는 중(내적 ≥ 0.55)이면 정지, 아니면 1.45 m/s로 접근. 대사창 중에도 정지
3. 0.55m 안에 오면 잡힘 → 붉은 화면 “들켰다” 1.8초 → 복도 입구에서 재시작
4. 복도를 벗어나면 원위치

## Surplus Person에 이어지는 것

- 고정 카메라 + 컷 전환, 조사·대사창 구조 (`UI/DialogueBox`, `Interaction/InspectPoint`, `Camera/CameraZone` 등 스크립트 공용)
- “시선” 모티프 — 눈알 벽, 시선이 닿을 때만 멈추는 존재 → 창밖의 거대한 눈 아이디어
- 인형의 관절마다 붙은 내 이름표, 두 개씩인 그릇 — 정체성 모티프
