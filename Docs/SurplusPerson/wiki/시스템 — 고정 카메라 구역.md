# 시스템 — 고정 카메라 구역

> 상태: **진행 중** · 작성: 기획 · 최종 수정: 2026-11-15 03:00

- **시스템**: 고정 카메라 구역 (컷)
- **상태**: `확정`
- **우선순위**: `높음`
- **관련 씬**: [씬 1-1](<씬 1-1 — 소희 기상.md>)
- **최종 수정**: 2026-11-15

> [!NOTE]
> 구역마다 고정 카메라 1대. 소희가 구역에 들어서면 그 카메라로 바로 컷. 회전·줌·시점 전환 없음.

## 왜 필요한가

“큰 방 안의 작은 인물, 움직이지 않는 카메라”라는 그래픽 방향의 뼈대. 누군가 집 안을 들여다보는 시선과도 이어진다.

## 규칙

1. 구역(바닥 사각형 + 층)마다 카메라 1대, 구역에 들어서면 즉시 컷
2. 이동은 화면 기준(WASD = 위·왼쪽·아래·오른쪽). 컷되는 순간 키를 누르고 있었다면 컷 직전 방향을 잠깐 유지 → 방향이 갑자기 뒤집히지 않음. 키 조합이 바뀌거나 손을 떼면 현재 카메라 기준
3. 구역마다 톤(색·대비 등)을 따로 가질 수 있음 — 바꾼 값만 저장하고 나머지는 기본 톤을 따름. 컷에 맞춰 톤 전환
4. 연출용 카메라(오프닝: 창밖 컷, 시계 클로즈업)는 구역과 별개로 덮어씀

## 조작

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| W A S D | 화면 기준 이동 | 플레이 중, 대사창 닫힘 |
| Shift | 달리기 |  |
| 숫자키 1~8 | (개발용) 구역으로 순간이동 |  |

## 화면 · UI

- 화면 왼쪽 위: SURPLUS PERSON / 1-1 · 공간 이름
- 오른쪽 위 개발용 줄: 조사 n/4 · 진엔딩 조건(6:56) 미확인/확인 — 출시 전 숨김

## 예외 상황

| 상황 | 처리 |
| --- | --- |
| 구역 경계에 서서 왔다 갔다 | 경계마다 바로 컷 (히스테리시스 없음 — 필요하면 추가) |
| 대사 중 | 이동 막힘, 카메라 그대로 |

## 수치 · 데이터

| 항목 | 값 | 메모 |
| --- | --- | --- |
| 구역 | 소희의 방 · 2층 복도 · 2층 로비 · 거실(서쪽/동쪽, 계단 기준) · 서재 · 식당 · 손님방 · 부엌 | 목업 `CAMS` / 구역 도구 V |
| 연출 카메라 | 오프닝: 창밖 컷, 시계 클로즈업 |  |
| 내부 해상도 | 480×360, 4:3 |  |

## 구현 메모

> [!IMPORTANT]
> 유니티: `Camera/CameraZone.cs`(트리거 진입 시 카메라 전환) + `Camera/ShotRig.cs`(컷신 구도 덮어쓰기). 목업의 구역 사각형·카메라 위치는 편집 모드 “값 내보내기”로 뽑아 옮긴다.
