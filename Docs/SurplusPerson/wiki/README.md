# 기획 위키 저장 폴더

`Docs/SurplusPerson/SP_Wiki.html`(기획 위키)에서 **폴더 연결**로 이 폴더를 고르면, 문서가 여기에 자동 저장됩니다.

- `wiki.json` — 위키 전체 원본 데이터 (페이지, 버전 기록)
- `INDEX.md` — 페이지 목차
- `<페이지 제목>.md` — 페이지별 Markdown (자동 생성. 직접 고치지 말고 위키에서 수정)
- `img/` — 문서에 넣은 이미지

`wiki.json`을 위키 밖에서 고칠 때는 `savedAt` 값을 현재 시각(ms)으로 올려야 위키가 새 내용으로 인식합니다.
