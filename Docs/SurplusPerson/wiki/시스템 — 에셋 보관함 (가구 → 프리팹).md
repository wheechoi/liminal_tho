- **시스템**: 에셋 보관함 (편집 모드 B)
- **상태**: `진행 중`
- **우선순위**: `보통`
- **관련 씬**: —
- **최종 수정**: 2026-11-15

> [!NOTE]
> 가구 61종을 분류별 미리보기 그림으로 고르면 화면 가운데에 꺼내 물건 도구로 편집. 유니티로 옮길 때 **가구 하나 = 프리팹 파일 하나**.

## 왜 필요한가

가구를 코드 안에 하드코딩하지 않고, 유니티 프리팹과 1:1로 맞출 단위를 미리 정해 두려고.

## 규칙

1. 목업 코드의 `LIB` 목록 = 가구 하나씩 따로 만든 단위
2. 앞면은 +z, 기준점은 바닥 가운데, 단위 미터
3. 꺼낸 물건은 이름이 `추가/가구 이름 n`. 위치·회전·크기는 “값 내보내기”의 [보관함에서 꺼낸 물건]에 파일 이름과 같이 나옴
4. 가구 색 바꾸기(전체/클릭한 부분), 액자에 이미지 넣기(액자 비율로 잘라 맞춤)
5. 빼기 Delete, 되돌리기·저장·내보내기 포함

## 조작

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| B | 보관함 열기 (편집 모드) |  |
| 미리보기 클릭 | 화면 가운데에 꺼내기 |  |
| Delete / Backspace | 꺼낸 물건 빼기 | 보관함에서 꺼낸 것만 |
