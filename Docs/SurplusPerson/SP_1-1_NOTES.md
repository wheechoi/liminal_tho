## 그래픽 방향 (보내주신 레퍼런스 7장 → `Docs/SurplusPerson/refs/`)
공통점으로 뽑은 것:
1. **큰 방 안의 작은 인물, 움직이지 않는 카메라** (단면 저택 일러스트, 픽셀 어드벤처, PS2 인형의 방)
2. **잉크 외곽선 + 디더링 + 적은 색 수** (픽셀 아트, 1비트 만화, 붉은 포스터 톤)
3. **패턴이 많은 실내** — 줄무늬 벽지, 흑백 체크 바닥, 타원 러그, 금색 액자
4. 4:3 화면

적용:
- 게임 화면은 480×360으로 그린 뒤 화면 셰이더(`Shaders/IllustratedScreen.shader`)로 잉크선·디더링·색 제한·종이 질감을 입힘.
- 재질 `Materials/SP/M_SP_IllustratedScreen.mat`의 **Gradient Map Amount**를 올리면 레퍼런스 5번처럼 화면 전체가 한 가지 색조(기본: 갈색~붉은색~크림)로 물듦. 1-1은 0 (원래 색). **공포가 짙어질수록 올리는 연출 손잡이**로 쓸 수 있음.

### 에셋 보관함 (편집 모드 `B`, 2026-10-21~) — 유니티로 옮길 때 가구 하나 = 프리팹 파일 하나
- 목업 코드의 `LIB` 목록 = 가구 하나씩 따로 만든 단위. 앞면은 +z, 기준점은 바닥 가운데, 단위 미터. 아래 `파일 이름`이 나중의 프리팹 이름 (지금은 목업에만 있음, 파일은 아직 안 만듦)
- 꺼낸 물건은 이름이 `추가/가구 이름 n`. 위치·회전·크기는 편집 모드 `값 내보내기`의 `[보관함에서 꺼낸 물건]`에 파일 이름과 같이 나옴
- 부엌(식당 남쪽 아치로 연결, 식당 모듈에 포함)의 가구는 전부 보관함 가구로 만듦
- (2026-10-22~) 집에 처음부터 있던 물건·문·창, 따로 떨어진 공간의 큰 물건도 전부 보관함 에셋 (`ASSET_META`, 61종 → 124종). 같은 모양은 같은 파일 이름
- 물건 도구(`O`)에서 고르면: 에셋 이름 → 유니티 파일 이름 표시, **복제**(Ctrl+D), **빼기**(Delete, 처음부터 있던 것도 — 숨김이라 Ctrl+Z·저장 가능), **조사 범위** 추가·없애기·반지름, **대사**·숨은 대사·미리보기. 따로 있던 텍스트 도구(N)는 여기로 합침
- 문은 고를 수 있지만 옮기기·빼기는 막힘 (벽 구멍과 붙어 있어서). 서재·식당·손님방 문은 고르면 문(대사·범위)과 방 끌기가 같이 됨
- **구조물**(벽·바닥·천장·계단·장식)도 물건 도구로 클릭하면 골라짐. 방마다 `구조/<방 이름>` 하나로 묶여 있고(거실의 방 문 쪽 벽은 `구조/거실 벽 (방 문 쪽)`), 클릭한 부분만 노란 상자. **전체 색·클릭한 부분 색**만 바꿀 수 있고 옮기기·빼기·복제는 막힘. 보관함 에셋에는 안 들어감 (방 통째라). 방을 옮겨도 바꾼 색은 그대로
