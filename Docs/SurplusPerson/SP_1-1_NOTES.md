## 실행
- `SP_1-1_Wake.unity`를 열고 Play.
- 조작: ↑↓ 전진/후진, ←→ 회전, Shift 달리기, **E/Space/Enter 조사·대사 넘기기**, Q 뒤돌기, **V 시점 바꾸기**
- 오프닝 연출 중 E를 누르면 건너뜀 (개발용)
- 씬은 메뉴 `Surplus Person > Build Scene 1-1`로 처음부터 다시 만들 수 있음 (`Scripts/Editor/SPScene11Builder.cs`).
  **씬을 손으로 고친 뒤 이 메뉴를 누르면 고친 내용이 사라짐.** 대사·좌표는 이 파일에서 고치고 다시 생성하는 게 안전.
- 빌드 이름(Product Name)은 `Surplus Person`. 폴더·저장소 이름(`Liminal_tho`)은 Unity-MCP 경로 때문에 그대로 둠.

## 그래픽 방향 (보내주신 레퍼런스 7장 → `Docs/SurplusPerson/refs/`)
공통점으로 뽑은 것:
1. **큰 방 안의 작은 인물, 움직이지 않는 카메라** (단면 저택 일러스트, 픽셀 어드벤처, PS2 인형의 방)
2. **잉크 외곽선 + 디더링 + 적은 색 수** (픽셀 아트, 1비트 만화, 붉은 포스터 톤)
3. **패턴이 많은 실내** — 줄무늬 벽지, 흑백 체크 바닥, 타원 러그, 금색 액자
4. 4:3 화면

적용:
- 게임 화면은 480×360으로 그린 뒤 화면 셰이더(`Shaders/IllustratedScreen.shader`)로 잉크선·디더링·색 제한·종이 질감을 입힘.
- 재질 `Materials/SP/M_SP_IllustratedScreen.mat`의 **Gradient Map Amount**를 올리면 레퍼런스 5번처럼 화면 전체가 한 가지 색조(기본: 갈색~붉은색~크림)로 물듦. 1-1은 0 (원래 색). **공포가 짙어질수록 올리는 연출 손잡이**로 쓸 수 있음.

## 확인 필요 (기획)
- **창문 대사**: 원문 "날씨 좋다. → 하늘이 구름 한점 없이 푸르다."의 화살표를 "이어서 나오는 두 줄"로 해석함. "두 번째 조사부터 다른 대사"라면 `repeatLines`로 옮기면 됨. ("구늘" → "구름"으로 고침)

- 숨은 대사를 본 뒤 시계 숫자를 10:34로 되돌릴지, 06:56으로 남겨둘지.
